§3使用方式

  1. 每卷 HTML 默认 全部折叠——只看题目；点击题目展开答案。
  2. 手机端原生支持折叠（HTML5 <details>，零 JS），公交地铁也能刷。
  3. 建议按 L1 → L2 → L3 的顺序刷；同等级内按频次从高到低。
  4. 答案 ≤200 字，便于背诵；超长的拆"答 / 易错 / 延伸"三段。
  5. 每题答案都经过 跨模型审查（Claude 写 / GPT-5.5 xhigh 审查）。
