具身智能高频面试题库

秋招冲刺向 · 题目来自公开面经

覆盖具身智能算法岗的 7 个核心方向：通识基础、RL 算法、VLA / 模仿学习、世界模型 / Sim2Real、工程落地、腿足机器人运动控制 / 全身控制 / 遥操作、3D 感知 / SLAM / VLN / 零样本 ObjectNav / Embodied VLM。 题目来自牛客、知乎、小红书、一亩三分地等公开面经，同义题合并后频次 ≥3 才入卷。 每题答案经独立审查后发布。

§1八卷目录

VOL · 01 通识基础 54 题

深度学习的梯度、归一化、Transformer 等基本功；强化学习的 MDP、贝尔曼方程、Q-learning 等入门概念；以及机器人学绕不开的坐标变换、雅可比矩阵和控制频率。一面常从这里开题，建议先扫一遍补齐知识盲区。新增 §H 手撕代码 10 题（Attention / LayerNorm / RMSNorm / BN / Bellman / REINFORCE / 高斯 KL / VAE ELBO）。
VOL · 02 RL 算法 50 题

把强化学习的主要算法挨个拆开来问——PPO、SAC、TD3、DDPG 的设计动机与取舍，CQL / IQL 等离线 RL 怎么解决分布外动作高估，RLHF 与 DPO / GRPO 在大模型对齐里的角色。技术深度比卷一高一档，二面三面常考的"为什么这么设计"集中在这里。新增 §H 手撕代码 10 题（Q-learning / DQN / PPO clipped / GAE / TD3 / SAC / DPO / GRPO 等核心公式手撕）。
VOL · 03 VLA / 模仿学习 66 题

具身智能 2024-2026 最热的方向——OpenVLA、RT-2、π 系列、GR00T-N1 等视觉-语言-动作模型的架构与差别；Diffusion Policy、ACT、Flow Matching 等动作生成方式的对比；模仿学习从行为克隆到 DAgger 的演进。投 VLA 算法岗几乎必问。新增 §H 手撕代码 8 题（BC / Diffusion Policy 训练 step / ACT chunking loss / OpenVLA action token / CLIP InfoNCE / DAgger / cross-attention / KV cache）。
VOL · 04 世界模型 / Sim2Real 31 题

让机器人在脑子里"做梦"训练的世界模型流派——Dreamer 系列、TD-MPC2、V-JEPA 2 的设计思路；以及仿真到真机迁移的工程命题——域随机化、教师-学生蒸馏、Isaac Lab / MuJoCo / Genesis 的取舍。人形和四足公司这两年面试的重点。
VOL · 05 工程落地 47 题

从算法到产品要踩的工程坑——VLA 怎么塞进 Jetson Orin 跑实时推理，FSDP / ZeRO 怎么选，teleop 数据采集流程，DROID 和 Ego4D 等数据集的位置；最后一节是开放题与系统设计，例如"给你一年时间和一支队伍，怎么做一台家务机器人"。新增 §H 手撕代码 8 题（数值稳定 softmax / LogSumExp / cross-entropy / KL / train loop / warmup+cosine / Adam / dropout）。
VOL · 06 腿足机器人控制 / 全身控制 / 遥操作 58 题

人形和四足公司面试的硬核底层——浮动基座动力学、MIT Cheetah 的 Convex MPC、WBC / TSID 任务优先级、RL-based locomotion（RMA / Walk These Ways / ASAP）、Apple Vision Pro 遥操作、HumanPlus / OmniH2O / ExBody 全身模仿、actuator network 和域随机化 sim-to-real。投宇树 / 智元 / 银河通用 / 星海图 / Figure / 1X 等岗位绕不开。新增 §H 控制类手撕代码 10 题（PID / anti-windup / KF / EKF / LQR / 四元数 / 数值 IK / 互补滤波 / DH FK / MPC QP）。
VOL · 07 3D 感知 / SLAM / VLN / 零样本 ObjectNav / Embodied VLM 67 题

具身导航算法岗的核心面——点云 / 深度估计 / NeRF 与 3DGS、ORB-SLAM3 / VINS-Fusion / 因子图、Nav2 / 占用栅格 / 路径规划是底层基本盘；上层覆盖 VLN（R2R / RxR / REVERIE / HAMT / DUET / NaVid / Uni-NaVid / NaVILA / VLN-R1）、零样本 ObjectNav（SemExp / ZSON / L3MVN / VLFM / OpenFMNav / CoW / PIRLNav）、Embodied VLM（CLIP / SigLIP / Grounding DINO / SAM 2 / VLMaps / ConceptFusion，含幻觉处理与延迟取舍）。VLN/导航研究方向的算法岗专用。新增 §H 手撕代码 7 题（IoU / NMS / Conv 维度 / BFS·DFS / A*·Dijkstra / K-Means / ViT patch embedding）。
VOL · 08 通用工程：LeetCode 高频 + 系统设计 40 题

脱开具身主题、聚焦"通用工程能力"的一卷——§1 LeetCode 高频 30 题（无重复字符最长子串 / 反转链表 / 三数之和 / LRU / 接雨水 / 滑动窗口最大值 / 编辑距离 / LIS 等，来自 CodeTop 与跨公司面经合并）；§2 ML 系统设计 5 题（VLA 训练 pipeline / VLA 推理服务 / RLHF 数据采集 / multi-robot fleet / LLM batch inference）；§3 机器人系统设计 5 题（perception-planning-control 全栈 / multi-sensor fusion / VLN agent / SLAM 状态估计 / ROS 2 双臂节点架构）。所有具身 / 自动驾驶 / VLA 岗一面 coding + senior 面 system design 都吃这卷。

§3使用方式

  1. 每卷 HTML 默认 全部折叠——只看题目；点击题目展开答案。
  2. 手机端原生支持折叠（HTML5 <details>，零 JS），公交地铁也能刷。
  3. 建议按 L1 → L2 → L3 的顺序刷；同等级内按频次从高到低。
  4. 答案 ≤200 字，便于背诵；超长的拆"答 / 易错 / 延伸"三段。
  5. 每题答案都经过另一组独立 AI 二次审查后发布，减少单一模型的事实错误。
